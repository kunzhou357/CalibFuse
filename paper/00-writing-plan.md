# CalibFuse 论文总体写作方案(v2,2026-09-28)

> v2 核心变化:确立**排列组合定位论**为总纲。论文 = **问题(唯一不可替代的资产)× 组合(被问题锁死的装配)× 工作量(审稿人的底气)× 格式(零扣分项)**。方法层面不与审稿人争"科学创新",所有高地都建在"问题的显而易见性"上。
> 定位:英文论文,默认 8 页顶会主线;期刊版在骨架上扩分析与消融。

## 0. 总纲:四要素定位论

| 要素 | 角色 | 对应动作 |
|---|---|---|
| **问题** | 唯一资产,卖点之首 | 打磨到"显而易见却被集体忽略",见 §1 |
| **组合** | 问题的必然推论,不装成发明 | 装配表 + "组合必然性"话术,见 §2 |
| **工作量** | 审稿人的信心来源 | 数量化的工作量外显清单,见 §5 |

一句话总纲:**审稿人读完 Introduction 应该说的是"这个问题太显然了,怎么一直没人做",而不是"这个方法真新颖"。** 前者是接受,后者是攻击的开始。

## 1. 第一资产:问题陈述的打磨

### 1.1 问题陈述(v2.1,以 paper/01-problem-statement.md 为准)

**核心(重新框架权)**:
> 退化鲁棒融合一直被框架成"恢复放在哪"的架构问题(级联解耦 / 一体化硬回归 / 互耦合);我们把它重新框架为**信任分配问题**——退化毁掉的不是像素,是信任,而"信什么、信多少"至今没有被任何方法显式定义、监督、检验过。

- "退化融合是空白/被忽略"的措辞**全局禁用**(方向已拥挤:Text-IF CVPR24、Deno-IF NeurIPS25、Dream-IF AAAI26、ReCoFuse CVPR26 等);
- 锋利钩子(标准融合损失奖励噪声:梯度项偏爱噪声、max 强度项偏爱散粒)保留,但降为**机制证据**(Intro 第 3 段 + 定量小实验),头牌让位于信任分配的重新框架;
- "为什么被忽略"的三条结构性解释:基准文化(干净配对)、恢复视角(引入的是架构问题)、形式化看似不可得(缺 benefit 的 ground truth——恰是我们的 clean-teacher 闭式增益补上的洞)。

### 1.2 显而易见性检验(三测,P1 定稿前通过)

1. **外行测试**:把常识档陈述念给非本方向的人听,反应应是"这不是显然的吗"——若得到"所以呢?",重写;
2. **后见之明测试**:审稿人读完应觉得"我早该想到",而不是"这问题存在吗";
3. **结构解释测试**:"为什么被忽略"必须有结构性答案,绝不暗示别人傻——答案已备好:**IVIF 社区的基准文化**(MSRS/M3FD/LLVIP 全是干净对)让退化输入天然落在评测盲区;退化被当成 low-level 礆另一个领域的事,两个社区在河两岸各修各的路。

### 1.3 忽略的代价 = Fig.1(动机图)

同一场景的退化输入,过 3 个代表性 SOTA(通用融合 / 恢复感知 / 级联降噪+融合)与 ours:基线噪声放大或互补信息丢失,ours 稳定。一张图同时完成"问题存在 + 现有方案失效 + 我们的方向有效"三件事。

## 2. 排列组合:装配表与话术

### 2.1 装配表(把借来的摆在明面上,每行都大大方方引用)

| 零件 | 出处 | 在本文的角色 | 我们的改动 |
|---|---|---|---|
| Transformer 骨干块 | Restormer(MIT,已署名) | 特征编码 | 仅工程参数 |
| 字典/基学习恢复 | 经典字典学习、CDDFuse 一系 | 模态内去退化 | 加 benefit-calibrated adoption 门 |
| 门控注意力 | 常规件 | 跨模态消息 | gate 分解 = 幅度上限 × 课程 × 源可靠性 × 预测收益 |
| Mean teacher / EMA | 半监督学习 | 干净监督源 | 提供 ridge-optimal gain 目标 |
| Ridge 回归闭式解 | 教科书 | "benefit"的定义 | 用于 gate 的回归监督 |
| 课程学习 | curriculum learning | 训练稳定性 | 恢复先行,budget 5→20 epoch 线性 ramp |
| 传感器物理噪声模型 | 成像物理文献 | 退化协议 | 参数固定、可复现、四态平衡 |

### 2.2 组合必然性话术(核心包装动作)

标准句式:**不说"我们提出 X",说"问题要求每一次信息传递都被校准;校准所需的零件——字典、门控、教师、闭式增益——都已存在,缺的只是按问题的要求装配,并给'收益'一个可监督的定义。"**

这是防守最强的姿态:没有任何单点可被攻击为"不新",而整体装配无可替代。配套红线:
- 不与审稿人争单点新颖性,争"**这是这个问题的正确装配**";
- "统一校准视角"降格为**装配逻辑**(wiring logic),是粘合剂不是发明;
- Related Work 里主动把每个零件归还给出处——大方是最强的进攻。

## 3. 全文逻辑主线(问题链,更新版五段)

1. **现象与 stakes**:IVIF 成熟,但训练与评测默认干净配准输入;真实传感器不同时干净(物理退化清单);
2. **立靶(问题的实证)**:(a) 融合网直接吃噪声 → 损失奖励噪声,放大退化;(b) 先降噪后融合 → 独立重建目标抹掉近噪声底的弱互补信号 + 级联误差;Fig.1 兜底;
3. **问题要求什么**:逐像素、逐模态的信任校准。追问:**"有益"怎么定义?**现成零件直接拼为什么不行——没有定义的 gate 只是 trick(与 gated-attention 工作的分水岭);
4. **装配(一口气)**:三层校准(adopt 校正 / gate 消息 / teacher 监督)+ clean EMA teacher 把 benefit 定义为 ridge-optimal gain(闭式、可回归)+ 四态平衡训练 + 恢复先行课程;
5. **贡献 + 一句结果**。

Method 章问题链不变:形式化 → 总览 → 模态内校准 → 模态间校准 → benefit 凭什么可信 → 训练协议。每小节:**设计问题 → 机制 → 为什么替代装配不行**。

## 4. 贡献表述(问题为纲,重排)

- **C1(问题+基准,头牌)**:指出并实证被忽略的问题——融合损失在退化输入下奖励噪声、级联降噪毁互补;给出物理启发退化协议与四态平衡设定;
- **C2(必然装配)**:由问题导出的三层校准装配,benefit 首次获得闭式、可监督的定义(ridge-optimal gain);
- **C3(实证规模)**:10 个方法 × 3 数据集 × clean/degraded 双条件的统一复评 + 机制级消融 + 可靠性/gate 行为分析;
- **C4(轻量与可复现)**:1.63M 参数,退化下显著领先、干净下不掉点;协议与代码公开。

claim–evidence 对账表(写作期维护):C1→Fig.1+损失行为分析;C2→Tab.3 消融+gate-增益相关曲线;C3→Tab.1/2+分析图组;C4→Tab.4 效率+主表。**claim 无证据不写,证据不支持就改 claim。**

## 6. 实验欠账(动笔前必须解决)

1. **基线统一复跑**(同数据、同协议、官方代码;含级联两档)——intro 立的靶必须自己打。清单(v2.1 更新):**退化家族** Text-IF、Deno-IF、Dream-IF、ReCoFuse(CVPR26,有代码)、OmniFuse、BA-Fusion + **经典干净融合** CDDFuse、SwinFusion、TarDAL + **级联两档**(Restormer 去噪 + 融合)。参数量对比借 Deno-IF 的气泡图式(我们 1.63M vs Text-IF 215M / DDFM 552M);
2. **指标协议决策(最大前置风险)**:calibfuse-metrics-v1 是内部协议,不能与文献数字同表;论文主表换社区标准协议统一复算所有方法,内部协议留附录交叉验证;
3. **数据出处文档**:MSRS/M3FD/LLVIP 正式引用 + test_noise 生成设置(datasets/README.md 自认缺失);
4. gate 行为分析实验(相关曲线、关断统计);
5. GPU 效率数据(CPU 40 s/张不进论文);
6. (加分)真实退化样本,回应"合成噪声泛化性"质疑。

## 7. 格式军规(零扣分项)

1. **模板与配额**:venue 官方模板;8 页配 6 图 + 4-5 表;
2. **图**:统一字体字号(图内字号 ≥ 正文)、colormap、放大镜框颜色与线型;对比图三件套(vis/ir/fused)+ zoom patch + 误差图同版式;
3. **表**:最优加粗、次优下划线;统一小数位;同一指标全文一个定义;
4. **符号与术语**:动笔前建符号表($I^{obs}_v, I_v, r, g, \alpha^*$…)与术语表(benefit/reliability/adoption/gate/budget/teacher),LaTeX macro 化(`\model`、`\obs`),一次定义全文不换词;
5. **引用策略**:50±10 条,近三年 ≥60%;必引清单 = 全部基线 + 全部装配零件 + 领域综述 + 潜在审稿人代表作;claim 与被引工作严格一一对应;
6. **语言**:主动句、动词开头;时态统一(方法现在时、实验结果现在时/过去时全文一致);摘要、贡献、结论三处 claim 措辞**逐字对齐**;
7. **诚实装置**:Limitations 节(合成噪声、配准假设)+ 统一协议声明 + 失败案例。
