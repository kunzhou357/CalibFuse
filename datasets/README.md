# Dataset setup

Place dataset files here yourself or pass another root with `--data`.
No dataset images are included in the Git source distribution.

```text
train/vis/example.png      train/ir/example.png
test/vis/example.png       test/ir/example.png
test_noise/vis/example.png test_noise/ir/example.png
```

The loader also accepts `visible`/`vi` and `infrared`/`inf`. Supported extensions
are PNG, JPEG, BMP, TIFF. Pairing uses the filename stem, so `example.jpg` and
`example.png` may pair across modalities. Avoid duplicate stems within a modality.
The current loader uses the intersection of stems: unmatched files are skipped.
Check pair counts before reporting results. Training requires at least four pairs.

The training split has 1,083 training pairs and 361 test pairs. Dataset
release names, download URLs, source licenses, and original test-noise generation
settings are not recorded in this repository. Supply those details
for the paper/public release; directory names alone do not establish dataset provenance.

Use every pair in the provided training split. Do not merge test images into it.
Online training degradation rotates four balanced states: clean, visible noisy,
infrared noisy, both noisy. Visible noise uses Poisson/read noise; infrared noise
uses Gaussian noise, stripes, and bad pixels. Parameters live in `utils/degradation.py`.
Existing `test_noise` is a fixed benchmark, not regenerated by the training loader.
For comparable tables, share its generation protocol and file hashes or licensed
download location.
